# Choix techniques

pour ce projet l'équipe a décidé d'opter pour un désign d'OTTO se rapprochant d'un plot de signalisation comme ceux que l'on retrouve dans le domaine du batiment.
En suivant cette ligne directrice nous avons aussi décidé d'équiper notre OTTO d'une pelleteuse  afin de pouvoir renverser les OTTO des autres groupes lors des épreuves le demandant.
